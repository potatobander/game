# 山野快递 · HILL & WHEEL

卡通风格的 2D 横版登山赛车，使用原生 HTML、CSS、Canvas 和 JavaScript 编写，无第三方运行依赖、无需构建。

**在线游玩：https://potatobander.github.io/game/**

## 玩法
- → / D / 右侧油门踏板：地面加速、空中抬头。
- ← / A / 左侧刹车踏板：减速后倒车、空中压头。
- P / Esc：暂停与继续。切换窗口或标签页时自动暂停。
- 行驶消耗燃油，沿途红色油桶补充最大容量的 45%，不超过油箱上限。
- 每枚金币价值 10；金币拾取后立即入账，翻车和重开都不会扣除。
- 翻车或燃油耗尽结束旅程，可重试或回车库。
- 不断延伸的山路、悬挂碰撞、重力、空中平衡、烟尘和可选音效。
- 支持手机竖屏、横屏及多点触控，松开踏板或切换窗口不会卡油门。

## 车辆与升级
- 山野小吉普：免费初始车辆。
- 逐风沙滩车：450 金币，动力和极速更高。
- 森林大脚车：950 金币，抓地力和油箱更强。
- 每辆车可单独升级引擎、轮胎和油箱，各 4 次，费用依次为 100 / 180 / 300 / 460 金币。
- 引擎每级动力 +23%，同时增加最高速度；轮胎每级抓地力 +13% 并增强车身回正；油箱每级容量 +20%。
- 金币、车辆、升级和最远纪录保存在当前浏览器的 localStorage，键名为 hill-wheel-save-v1。不同设备/浏览器之间不会同步；清除网站数据会清除存档。存储受限时仍可游玩，但无法保证跨会话保留进度。

## 本地运行
需要 Node.js 18 或更新版本，在仓库目录执行：

~~~sh
npm start
~~~

访问 http://127.0.0.1:4173 。页面使用 ES modules，需要通过 HTTP 服务访问。

## 测试
~~~sh
npm test
~~~

覆盖行驶与耗油、拾取与补给、重复拾取、刹车倒车、空中旋转、翻车结束、长距离数值稳定、升级实际效果、购买扣款、等级上限和存档恢复。

浏览器实测：桌面方向键、390px 手机布局、按住踏板、暂停、升级扣款、购买沙滩车、刷新后存档保持。

## 部署
GitHub Pages 从 main 分支根目录发布；.nojekyll 使其作为静态网站部署。修改后推送 main 即会触发 Pages 构建。

## 文件
- index.html / style.css：页面、车库和响应式界面。
- engine.js：独立物理、赛道、燃油、收集和经济系统。
- render.js：全部原创 Canvas 绘图，无外部图片或字体请求。
- game.js：交互、状态、声音、存档和帧循环。
- tests/engine.test.mjs：核心规则测试。
- server.mjs：仅供本地开发的静态服务。
