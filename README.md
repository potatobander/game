# 黄金矿工 · Gold Rush

暖色矿洞风格的中文网页小游戏。原生 HTML / CSS / Canvas / JavaScript，零依赖，无需构建。

## 玩法

- 空格、下方向键或点击画面：在钩爪摆动时出钩。
- 上方向键、B 或炸药按钮：炸掉正在拖回的物品。
- P、Esc 或暂停按钮：暂停 / 继续。
- 60 秒内达成本关目标，依次挑战 8 个矿区。
- 通关后使用金币购买炸药、绞盘升级、加时怀表和钻石增值。
- 商店消费不扣减本关目标进度。最高纪录保存在当前浏览器本地。
- 手机支持触屏；音效可自行开启；切换标签页时自动暂停。

## 本地运行

直接用现代浏览器打开 `index.html`，或在本目录运行 `python -m http.server 8000`。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/(root)`，点击 Save。

所有画面使用 Canvas 绘制，无外部图片、字体、CDN 或网络接口依赖。
